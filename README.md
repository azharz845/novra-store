# NOVRA Store V2

Versi ini menambahkan:
- cinematic scroll reveal
- custom cursor
- interactive 3D tilt pada produk
- front/back flip 180°
- quick-view product modal
- size selector
- shopping bag
- checkout WhatsApp (checkout WhatsApp ke nomor toko yang sudah dikonfigurasi di `script.js`)
- responsive mobile
- dark editorial / luxury streetwear direction

Jalankan `index.html` dengan VS Code Live Server untuk pengalaman terbaik.


## HD assets
Product images were enlarged 4x and lightly sharpened so the browser is not stretching the original tiny source files directly.
